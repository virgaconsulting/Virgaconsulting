# Virga Consulting

Repository di produzione per **Virga Consulting** e **vFiscal**.

## Deploy Cloudflare Pages
- Branch di produzione: `main`
- Build command: `bash build.sh`
- Output directory: `dist`
- Framework preset: nessuno

La build ricostruisce la versione auditata del **3 ottobre 2026** partendo dal deployment Cloudflare stabile precedente e applicando le correzioni versionate in `.deploy/`.

Il dominio canonico è `www.virgaconsulting.it`.
